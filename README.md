# Website-TrafficAnalysis-EDA

## 🚀 Project Overview
This project performs a comprehensive analysis of website traffic data to uncover trends in user engagement, marketing performance, and traffic behavior across different quarters of 2023.

Using Excel-based data analytics techniques, the project transforms raw traffic data into meaningful business insights that support data-driven decision-making.

This analysis simulates real-world digital marketing performance evaluation.

## 🎯 Business Objectives
The goal of this analysis was to answer key performance questions:

-📌 What were the total clicks generated in Quarter 2 (April–June) of 2023?

-📌 Which traffic source had the third lowest overall traffic?

-📌 Which source delivered the best (lowest) Average Cost per Click (CPC)?

-📌 Which quarter recorded the highest average session duration for Direct traffic?

These questions reflect common digital marketing performance evaluations used in industry.

## 📊 Analytical Approach
The analysis was conducted using a structured workflow:

1️⃣ Data Cleaning & Preparation

Validated date formats

Extracted Month & Quarter

Organized traffic sources

2️⃣ KPI Computation

Total Clicks (Quarter-based aggregation)
Traffic ranking (ascending analysis)

CPC calculation using Spend / Clicks

Average Session Duration by Quarter

3️⃣ Visualization

Quarter-wise click trends

Traffic source comparison

Engagement duration analysis
